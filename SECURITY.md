# Security policy

## Reporting a vulnerability

Please report security problems **privately**. Do not open a public issue or pull request.

Use GitHub private vulnerability reporting: go to the repository's **Security** tab and choose
**Report a vulnerability** (https://github.com/Ahmad-AlModhayan/kahf-connect/security/advisories/new).

Include what you found, the version or commit, and steps to reproduce. Reports that touch the signed catalog,
signature verification, grant enforcement or audit are the most important.

## What to expect

Reports are answered within a cycle. We confirm the problem, tell you when a fix is planned, and credit you in the
advisory if you want that.

## Supported versions

| Version | Supported |
|---|---|
| Latest release | yes |
| Earlier releases | no |
| `main` | fixes land here first |

The SDKs are at 1.0.0-dev, so only the latest release gets fixes for now.
